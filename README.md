# tur_uzor_web

## Как правильно запустить игру

> Если открыть `index.html` напрямую (через `file://`), браузер часто блокирует ES-модули — поэтому экран может быть белым.

Запускайте через локальный HTTP-сервер:

### Вариант 1 (рекомендуется)
```bash
npm start
```

После запуска откройте:
- http://localhost:5173

### Вариант 2 (если нет npm)
```bash
python3 -m http.server 5173
```

И затем откройте:
- http://localhost:5173

## Если всё равно белый экран
1. Откройте DevTools (`F12`) → Console.
2. Проверьте, что страница открыта именно через `http://localhost:...`, а не `file://...`.
3. Попробуйте hard reload (`Ctrl+Shift+R`).
